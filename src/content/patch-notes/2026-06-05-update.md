## ✨ New features

- **My District**, a new hub for action where you live, with a widget that takes you there.
- **Light and dark themes** that follow you across devices, plus an Appearance page.
- **A clear status header on state pages**, with links to the bills behind it.
- **A feedback button** on every page for reporting a problem.

## 🐛 Fixes

- **Long links no longer run off the page.**
