A big stretch of work landed this week — a brand-new front door, a far more accurate legal-status map, and a sweep of fixes to the parts you use most. Every item links to the exact code that shipped it.

## ✨ New

- **A brand-new home page.** Visitors now land on a real front door: a live "what's happening right now" pulse, a state-by-state legal-status map, a candle in memory of Scot Rubi, and a faster way to get started. ([4f96f36](https://github.com/ohjustadam/ikratom/commit/4f96f36bd516036c57e04345479ff7c928c09a93))
- **The legal-status map now covers 37 states.** Each status was cross-referenced against the statute plus multiple independent sources and fact-checked before publishing — and we corrected Kansas (its new law schedules only 7-OH; the natural leaf stays legal). States we're still verifying stay grey, never a guess. ([90673b6](https://github.com/ohjustadam/ikratom/commit/90673b674d322092f4bd277340cf1db8499ebe37), [619cb1a](https://github.com/ohjustadam/ikratom/commit/619cb1a10447d28ba28405c6b4f7779e3850c7c2))

## 🐛 Fixes

- **One-click email actions are reliable again.** They no longer open a blank message or crash — they load your actual officials, every time. ([2b284ce](https://github.com/ohjustadam/ikratom/commit/2b284cee660b41410e97c1d4efc55ed8f812477b), [20f9709](https://github.com/ohjustadam/ikratom/commit/20f9709bb970406ab4ed66dbd419d0bdb1a95cbb))
- **Clean source links everywhere.** Alerts and the letters you send to officials now show a tidy, titled article link instead of a long Google-redirect URL. ([709f52e](https://github.com/ohjustadam/ikratom/commit/709f52ecd7238bfe26ab5749632aac6b4d68b714), [dbc4bb0](https://github.com/ohjustadam/ikratom/commit/dbc4bb0387e1d106631452d3cb82e3e353fc9dec))
- **Notifications load reliably again** — and we fixed the deeper bug behind it that had been quietly breaking one-click actions across the whole site. ([98bea0d](https://github.com/ohjustadam/ikratom/commit/98bea0d3e07d678552265b01dac304b72350c398), [9bbf442](https://github.com/ohjustadam/ikratom/commit/9bbf442bd944f3bbae3c24bc31a21cf34ca3e2b9))
- **Smarter alerts.** Alerts mislabeled to the wrong state are now caught and corrected, and campaigns only spin up for real, actionable events. ([f972e36](https://github.com/ohjustadam/ikratom/commit/f972e36c65f4f9841d57ce0568c38063bfb06ca5), [559b360](https://github.com/ohjustadam/ikratom/commit/559b360f6ea91c13e3c5441d907657a1709039d3))

## 🛠 Behind the scenes

- **Sturdier, self-healing data pipelines** — when one source hiccups, the rest keep going instead of failing the whole run. ([e182c22](https://github.com/ohjustadam/ikratom/commit/e182c226a734527505caaa9c1107e8f71c7c838f))
- **Legal data is published only after it's confirmed** — automatic guesses never reach the public map. ([35a0482](https://github.com/ohjustadam/ikratom/commit/35a0482ad7c45e3e50096f6f352ac24bd356857d))
